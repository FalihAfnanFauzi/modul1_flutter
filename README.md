## Daftar Proyek

### 1. `praktikum_widget` (Praktikum Mandiri)
Proyek pengenalan struktur widget dasar pada Flutter:
- `StatelessWidget`: Komponen kartu profil mahasiswa (`ProfilCard`).
- `StatefulWidget`: Komponen penghitung suka interaktif (`PenghitungSuka`) yang memperbarui status tampilan dengan `setState()`.
- Layout terstruktur menggunakan `SingleChildScrollView`, `Column`, dan `Row`.
